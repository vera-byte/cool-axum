配置文件默认读取 `config.yaml`，可用环境变量 `COOL_CONFIG` 指定路径。结构与 cool-admin-go 对齐。

## server

```yaml
server:
  address: ":8001"              # 监听地址
  nodeLabel: "bj-node-1"        # 可选：自定义节点标签（X-Node-Label / 链路 ID 前缀）
  openapiPath: "/api.json"      # OpenAPI 导出路径
  swaggerPath: "/swagger"       # Swagger 路径
  clientMaxBodySize: 104857600  # 最大 body（默认 100MB）
```

| 字段 | 默认 | 说明 |
|------|------|------|
| `address` | `:8001` | 监听地址 |
| `nodeLabel` | 未设置 | 节点标签；未设置时用 `{nodeId}@{port}`（nodeId 来自 `raft.nodeId`） |
| `openapiPath` | `/api.json` | OpenAPI 3.0 文档地址（免登录） |
| `swaggerPath` | `/swagger` | Swagger UI 地址（免登录） |

`nodeLabel` 会出现在响应头 `X-Node-Label` 与链路 ID 前缀中，便于多节点下辨识请求落到哪台机器，见 [API 参考 · 链路追踪](/api-reference#链路追踪)。
OpenAPI / Swagger 见 [API 参考](/api-reference#api-documents-openapi--swagger)。

## logger

```yaml
logger:
  level: "info"     # trace | debug | info | warn | error
  format: "text"    # text | json
  stdout: true
  # 文件输出（可选，按大小轮转）
  file:
    path: "./logs/cool-axum.log"
    maxSize: 10485760   # 单文件最大字节，默认 10MB
    maxFiles: 5         # 轮转保留个数（含当前），默认 5
```

| 字段 | 默认 | 说明 |
|------|------|------|
| `level` | `info` | 日志级别；`RUST_LOG` 环境变量可覆盖 |
| `format` | `text` | 输出格式，见下 |
| `stdout` | `true` | 输出到标准输出 |
| `file` | 未启用 | 文件输出；配置 `file.path` 即开启 |

### file：文件输出与按大小轮转

| 字段 | 默认 | 说明 |
|------|------|------|
| `path` | — | 日志文件路径（必填才会开启文件输出） |
| `maxSize` | `10485760`（10MB） | 写满后轮转 |
| `maxFiles` | `5` | 保留轮转份数（含当前文件） |

轮转规则：

```
cool-axum.log      ← 当前写入
cool-axum.log.1    ← 上一份
cool-axum.log.2
cool-axum.log.3
cool-axum.log.4    ← 最旧（超出 maxFiles 删除）
```

- `stdout: true` 且配置了 `file` 时，**同时**输出到控制台与文件
- `stdout: false` 时只写文件（适合生产）

### format = text（默认）

人读友好，**每行**含节点标识：

```
2026-10-26T16:35:56.799Z INFO node=text-node cool-axum 启动中... address=":8002"
2026-10-26T16:35:59.365Z INFO node=text-node request method=GET path="/health" status=200 cost_ms=1 trace=text-node-abc123
```

### format = json

结构化，便于 ELK / Loki 采集；每条含 `timestamp` / `level` / `node` / `message` / 业务字段：

```json
{"timestamp":"2026-10-26T16:35:57.389Z","level":"INFO","node":"json-node","message":"cool-axum 已启动，监听 0.0.0.0:8002"}
{"timestamp":"2026-10-26T16:35:59.365Z","level":"INFO","node":"json-node","message":"request","method":"GET","path":"/health","status":200,"cost_ms":"2","trace":"json-node-79119b02ccf3bc4f"}
```

级别说明：

| level | 典型内容 |
|-------|----------|
| `error` | 启动失败、种子插入失败、日志落库失败 |
| `warn` | HTTP ≥400、Raft 复制告警、降级回退 |
| `info` | 启动流程、请求日志、任务调度、Raft 状态 |
| `debug` | SQL、路由注册、模块 init、种子跳过 |
| `trace` | 最细粒度（一般不开） |

## database

支持多数据源分组，`default` 为默认组。

```yaml
database:
  default:
    type: "mysql"          # mysql | pgsql
    host: "127.0.0.1"
    port: "3306"
    user: "root"
    pass: "123456"
    name: "cooltest"
    charset: "utf8mb4"
    timezone: "Asia/Shanghai"
    debug: true
    createdAt: "createTime"   # 自动填充列名
    updatedAt: "updateTime"
    deletedAt: "deleteTime"   # 软删除列
  # 其他分组：
  # baseConfig:
  #   type: "pgsql"
  #   ...
```

## redis

```yaml
redis:
  cool:
    address: "127.0.0.1:6379"
    db: 0
    # password: "secret"
```

配置后 sa-token 自动使用 **Redis 会话存储**（多节点共享）；未配置则回退内存存储（单机开发）。

## cool

```yaml
cool:
  autoMigrate: true     # 启动时自动建表（IF NOT EXISTS）
  eps: true             # 前端 EPS 元数据
  file:
    mode: "local"       # local | minio | oss
    domain: "http://127.0.0.1:8002"
    oss:
      endpoint: "192.168.192.110:9000"
      accessKeyID: "accessKeyID"
      secretAccessKey: "secretAccessKey"
      bucketName: "cool-axum"
      useSSL: false
      location: "us-east-1"
  # 多租户（可选，对齐 cool-admin-midway v8.0）
  tenant:
    enable: true
    urls:
      - "/admin/**"
      - "/base/sys/**"
```

### cool.tenant（多租户）

| 字段 | 默认 | 说明 |
|------|------|------|
| `enable` | `false` | 是否开启数据隔离 |
| `urls` | `[]` | 需过滤租户的 URL，支持 `*` / `**` 通配 |

开启后 CRUD 自动按 `base_sys_user.tenantId` 隔离数据。详见 [多租户](/tenant)。

## modules.base

```yaml
modules:
  base:
    auth:
      sso: false
      secret: "cool-base88776655"
      tokenExpire: 36000        # token 有效期（秒）
      refreshExpire: 1296000    # 刷新有效期（秒）
    middleware:
      authority:
        enable: true            # 权限拦截
      log:
        enable: true            # 操作日志
```

## raft（可选）

启用后集群选主，**仅 Leader 执行定时任务**。详见 [分布式架构](/distributed)。

```yaml
raft:
  enable: true                  # 默认 false：单机模式，任务本地执行
  nodeId: 1                     # 本节点 ID（集群内唯一）
  selfAddr: "http://127.0.0.1:8001"
  dataDir: "./data/raft"        # RocksDB 持久化目录（每节点独立）
  peers:
    - "1:http://127.0.0.1:8001"
    - "2:http://127.0.0.1:8002"
```

| 字段 | 默认 | 说明 |
|------|------|------|
| `enable` | `false` | 是否启用 Raft 选主 |
| `nodeId` | `1` | 本节点 ID，须与 peers 中自己的条目一致 |
| `selfAddr` | — | 本节点 HTTP API 地址（节点间 RPC） |
| `dataDir` | `./data/raft` | RocksDB 目录（日志 / vote / applied-state） |
| `peers` | `[]` | 集群成员 `id:addr` 列表 |

各节点共用同一 `peers`，`nodeId` / `selfAddr` / `dataDir` 各自不同。最小节点 ID 负责 bootstrap；重启后从 `dataDir` 恢复并跳过 bootstrap。

## 文件上传配置

```yaml
cool:
  file:
    mode: "local"       # local | minio | oss
    domain: "http://127.0.0.1:8001"   # 返回 URL 的域名前缀
    oss:                # minio/oss 必填
      endpoint: "192.168.192.110:9000"
      accessKeyID: "accessKeyID"
      secretAccessKey: "secretAccessKey"
      bucketName: "cool-axum"
      useSSL: false
      location: "us-east-1"
```

| 模式 | 说明 |
|------|------|
| local | 落盘 `./public/uploads/Ymd/`，`/public/**` 静态暴露 |
| minio | S3 兼容对象存储 |
| oss | 阿里云 OSS（S3 兼容端点） |
