## task 定时任务

| 路由前缀 | 表 | 说明 |
|----------|----|------|
| `/task/info` | task_info | 任务定义（cron / 间隔） |
| `/task/log` | task_log | 执行日志（只读） |

### 调度器

| 能力 | 说明 |
|------|------|
| taskType=0 | cron 表达式（6 字段：秒 分 时 日 月 周），如 `0 0 2 * * *` |
| taskType=1 | `every` 间隔（毫秒），如 `every: 2000` = 每 2 秒 |
| service | `FuncName(arg)` 调用注册函数，如 `TaskTest(hello)` |
| startDate / endDate | 未到开始时间跳过本轮；过结束时间自动停 |
| limit | 执行次数上限，达到后自动停 |
| status | 1=启用（立即调度） 0=禁用（立即停） |
| 日志 | 每次执行写 `task_log`；成功日志每任务保留 **20 条**，失败全留 |

### 特殊接口

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/task/info/once` | `{"id":1}` 手动执行一次 |
| GET | `/task/info/status` | 运行中任务数 |

### 内置函数

| 函数 | 说明 |
|------|------|
| `TaskTest(param)` | 演示任务，打印日志 |
| `BaseFuncClearLog(deep)` | 清理旧任务日志；`deep=true` 连失败一起清 |

### 任务生命周期

```
add/update status=1  → 启用调度（覆盖旧任务）
update status=0      → 立即停止
delete               → 软删除（建议先 status=0）
启动加载              → 自动启用 status=1 的任务
```

## 调用示例

```bash
# 新增用户
curl -X POST http://127.0.0.1:8001/base/sys/user/add \
  -H "Authorization: Bearer $TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{"username":"zhangsan","password":"secret","name":"张三","status":1}'

# 用户分页 + 关键字
curl -X POST http://127.0.0.1:8001/base/sys/user/page \
  -H "Authorization: Bearer $TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{"page":1,"size":10,"keyWord":"zhang"}'

# 字典类型（key 为保留字，引擎自动加引号）
curl -X POST http://127.0.0.1:8001/dict/type/add \
  -H "Authorization: Bearer $TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{"name":"性别","key":"gender"}'
```

## 校验规则

模块内置：

- **唯一键**：如用户名、字典 key 重复返回 `code:1001`
- **非空**：如用户名、菜单名缺失返回业务错误
- **敏感字段**：用户 `password` / `passwordV` 在查询结果中自动剥离

## 路由分组与鉴权

| 分组 | 前缀示例 | 鉴权 |
|------|----------|------|
| **开放** | `/admin/base/open/*`、`/admin/dict/info/data` | 免登录 |
| **comm** | `/admin/base/comm/*` | 仅登录（Bearer/sa-token/Cookie 均可） |
| **业务** | `/admin/base/sys/*`、`/admin/dict/*` | 登录 + 权限点 |

**超管（userId=1 或 perms 含 `*`）无视权限校验**，任意业务接口直接放行。

## 模块注册机制（对齐 cool-admin-go）

### 路由自动注册

各模块通过 `route_groups()` 声明路由分组，注册中心自动装配（对齐 `cool.RegisterController`）：

```rust
// modules/base/src/lib.rs
pub fn route_groups<S>() -> RouteGroups<S> {
    RouteGroups::new()
        .open(open_routes::<S>())    // 免登录：captcha/login/eps
        .comm(comm_routes::<S>())    // 仅登录：permmenu/person/upload
        .biz(routes::<S>())          // 登录+权限：base_sys_* CRUD
}
```

`modules/modules.rs` 统一装配三组中间件：

| 分组 | 中间件 | 对齐 Go |
|------|--------|---------|
| open | 无鉴权 | `/admin/*/open/*` |
| comm | token 归一 | `/admin/*/comm/*` AuthComm |
| biz | check_login + authority | `/admin/*` |

### 模块初始化（对齐 base/base.go init）

各模块 `init()` 自治完成种子填充与专属启动：

```rust
// modules/base/src/lib.rs（对齐 base.go init()）
pub async fn init(db: &DbManager, cache: CacheManager) {
    tracing::debug!("module base init start ...");

    // FillInitData 逐表初始化
    cool_db::fill_init_data(db, "default", "base_sys_menu", initjson::MENU).await;
    // ...8 张表

    login::init_cache(cache);      // 模块专属
    login::seed_admin_if_empty(db).await;

    tracing::debug!("module base init finished ...");
}
```

### 新增模块接入

```rust
// 1. modules/foo/src/lib.rs
pub fn spec() -> ModuleSpec { ModuleSpec::new("foo").tables(all_tables()) }
pub fn init(...) { /* FillInitData + 专属启动 */ }
pub fn route_groups<S>() -> RouteGroups<S> { ... }

// 2. modules/modules.rs 的 registered() 加一行
("foo", mod_foo::route_groups::<S>),
```

表 / 种子 / 路由 / 启动钩子即自动接入。
