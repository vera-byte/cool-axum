## cool-axum 是什么

**cool-axum** 是将 [cool-admin-go](https://github.com/cool-team-official/cool-admin-go)（GoFrame CRUD 后台框架）完整移植为 **Rust / Axum** 的实现。

它提供：

- **通用 CRUD 引擎**：定义表结构后自动获得 `add / delete / update / info / list / page` 六个标准接口
- **登录鉴权**：基于官方 [sa-token-rust](https://github.com/sa-tokens/sa-token-rust)，支持多节点共享会话
- **系统管理模块**：用户 / 角色 / 菜单 / 部门 / 参数 / 日志
- **业务模块**：数据字典、定时任务、文件空间、示例模块
- **多节点部署**：无状态应用 + Redis 会话，Docker / K8s 水平扩展
- **Raft 选主**：集群内仅 Leader 执行定时任务，避免重复调度
- **多租户**：`tenantId` 列级数据隔离，CRUD 自动注入（对齐 cool-admin-midway）

## 技术栈

| 组件 | 选型 |
|------|------|
| Web 框架 | axum 0.8 |
| 鉴权 | sa-token-rust / sa-token-plugin-axum |
| 数据库 | sqlx（MySQL / PostgreSQL） |
| 会话/缓存 | Redis |
| 分布式选主 | openraft（任务单点执行） |
| 文档 | Mintlify |
