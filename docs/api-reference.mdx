## 统一响应体

```json
{
  "code": 1000,
  "message": "success",
  "data": {}
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| code | int | 业务码 |
| message | string | 提示信息 |
| data | any | 数据（可选） |

## 错误码

| code | 含义 |
|------|------|
| 1000 | 成功 |
| 1001 | 业务失败（校验/唯一键等） |
| 51 | 参数错误 |
| 1003 | 内部错误（SQL 等） |
| 401 | 未登录（HTTP 401） |
| 403 | 无权限 |
| 404 | 未找到 |
| 500 | 服务器错误 |

## 需登录接口

所有业务 CRUD 挂在登录校验之下，携带 `Authorization: Bearer <token>`。

### 通用 CRUD 模式

每个资源六接口（`{prefix}` 为资源前缀）：

| 方法 | 路径 | Body/Query |
|------|------|------------|
| POST | `{prefix}/add` | JSON 字段 |
| POST | `{prefix}/delete` | `{"ids":[1,2]}` |
| POST | `{prefix}/update` | `{"id":1, ...}` |
| GET | `{prefix}/info` | `?id=1` |
| POST | `{prefix}/list` | 过滤 / `keyWord` / `order` / `sort` |
| POST | `{prefix}/page` | `page` / `size` / 过滤 / `isExport` |

## 登录接口

### POST /base/login

```json
// req
{ "username": "admin", "password": "admin123" }

// res
{
  "code": 1000,
  "data": {
    "token": "...",
    "userInfo": { "id": "1", "username": "admin" },
    "permissions": ["*"]
  }
}
```

### GET /base/userinfo

```json
{
  "code": 1000,
  "data": { "id": "1", "permissions": ["*"], "roles": ["admin"] }
}
```

## 文件上传

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/base/comm/uploadMode` | 当前存储模式（local/minio/oss） |
| POST | `/base/comm/upload` | multipart 上传，字段名 `file` |

```bash
curl -X POST http://127.0.0.1:8001/base/comm/upload \
  -H "Authorization: Bearer $TOKEN" \
  -F "file=@/path/to/photo.png"
```

响应：

```json
{
  "code": 1000,
  "data": {
    "url": "http://127.0.0.1:8001/public/uploads/20261023/<uuid>_photo.png",
    "mode": "local"
  }
}
```

local 模式下 `/public/**` 为公开静态目录，可直接访问上传文件。文件名自动安全化（去除路径分隔符、特殊字符），并加 UUID 前缀防覆盖。

## 开放接口（免登录）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/admin/base/open/captcha` | 图形验证码（`?height&width&color`） |
| POST | `/admin/base/open/login` | 登录（可带 `captchaId`/`verifyCode`） |
| POST | `/base/login` | 登录（别名） |
| GET | `/admin/base/open/eps` | EPS 元数据 |
| POST/GET | `/admin/dict/info/data` | **字典数据（匿名可访问）** |

### GET /admin/base/open/captcha

```
/admin/base/open/captcha?height=45&width=150&color=%232c3142
```

```json
{
  "code": 1000,
  "data": {
    "captchaId": "fcbd15872e5c418b...",
    "data": "data:image/svg+xml;base64,..."
  }
}
```

### POST /admin/base/open/login

请求（camelCase，可选验证码）：

```json
{
  "username": "admin",
  "password": "123456",
  "captchaId": "<可选>",
  "verifyCode": "<可选>"
}
```

响应（对齐 cool-admin-go TokenResult）：

```json
{
  "code": 1000,
  "data": {
    "expire": 36000,
    "token": "e6531587dd6bad6a...",
    "refreshExpire": 1296000,
    "refreshToken": "e6531587dd6bad6a...",
    "userInfo": { "id": 1, "username": "admin", "name": "超级管理员", "passwordV": 1 },
    "permissions": ["*"]
  }
}
```

### POST /admin/dict/info/data

字典数据查询，**匿名可访问**：

```bash
# POST body
curl -X POST http://127.0.0.1:8001/admin/dict/info/data \
  -H 'Content-Type: application/json' \
  -d '{"types":["type","brand"]}'

# GET query
curl 'http://127.0.0.1:8001/admin/dict/info/data?types=type'
```

响应（前端 `label=name, value=id`）：

```json
{
  "code": 1000,
  "data": {
    "type": [{ "id": 1, "name": "衣服", "parentId": null, "typeId": 1 }],
    "brand": [{ "id": 4, "name": "闪酷", "parentId": null, "typeId": 2 }]
  }
}
```

`types` 为空返回全部字典类型。

## 令牌传递方式

任意一种均可（自动归一）：

| 方式 | 示例 |
|------|------|
| Bearer | `Authorization: Bearer <token>` |
| Raw | `Authorization: <token>` |
| sa-token 头 | `sa-token: <token>` |
| Cookie | `Cookie: satoken=<token>` |

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/admin/base/comm/permmenu` | 权限点 + 菜单树 |
| GET | `/admin/base/comm/person` | 当前登录人信息 |

## 请求日志

每个请求自动输出控制台日志并写入 `base_sys_log`：

```
request method=POST path="/admin/base/sys/user/page" status=200 cost_ms=4
```

| 字段 | 说明 |
|------|------|
| userId | 登录人 ID（未登录为 0） |
| action | `METHOD:path` |
| ip | 客户端 IP（支持 X-Forwarded-For） |
| params | query 串，敏感字段脱敏 |

跳过 `/health`、`/public/*`、`/captcha`。
